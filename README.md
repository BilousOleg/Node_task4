# Express App with Sequelize Model

Навчальний проект для практичного закріплення роботи з **Sequelize ORM**

# База даних

Реалізовано такі моделі:

- **Phone**
- **Preorder**

у відношенні (Phone) 1:n (Preorder)

## Для керування структурою бази даних використовуються Sequelize migrations.

## Для тестових даних використовуються Sequelize seeders.

## В моделях Sequelize визначені:

- типи даних;
- allowNull;
- defaultValue;
- model-level validators;
- унікальні обмеження;
- обмеження CHECK на рівні бази даних.
- зовнішні ключі
- асоціації на рівні ORM

# Сервер

Для обробки запитів до бази даних від будь-яких http-клієнтів був створений http-сервер з використанням фреймворку **Express**

## Endpoints

Додана обробка таких endpoints:

**Phone:**

- **POST /api/phones** - додавання нового запису
- **GET /api/phones** - отримання певної кількості записів
- **GET /api/phones/:id** - отримання конкретного запису
- **PATCH /api/phones/:id** - оновлення запису
- **DELETE /api/phones/:id** - видалення запису
- **PATCH /api/phones/:id/images** - зміна файлу зображення
- **GET /api/phones/:id/preorders** - отримання передзамовлень (через асоціацію з Preorder)
- **POST /api/phones/:id/preorders** - додавання передзамовлення (через асоціацію з Preorder)

**Preorder:**

- **GET /api/preorders** - отримання всіх передзамовлень (з додатковими полями через асоціацію з Phone)

## Routers

Створено розгалуження шляхів за допомогою Router з Express

Основні розгалуження:

- **/api** - головне розгалуження сервера
- **/api/phones** - розгалуження для сутностей Phone
- **/api/preorders** - розгалуження для сутностей Preorder

## MVP

Проєкт створено з дотриманням архітектурного стилю **Model View Presenter (MVP)**, хоча частини відображення (View) немає.

Через це, у проєкті наявні:

- Модель, яка відповідає за звернення до бази даних і обробку даних
- Контролери та middleware, які відповідають за обробку запитів і надсилання http-відповіді

## Валідація

У проєкті наявна валідація даних, що надсилаються у форматі JSON від будь-якого http-клієнта за допомогою **Yup** та вбудованих можливостей **Sequelize** на рівні моделі.

## Обробка помилок

Реалізовані обробники помилок - middleware, які оброблюють створені за допомогою **http-errors**, валідації тощо помилки і відправляють їх у якості http-відповіді.

## Додавання файлів

Реалізовано додавання файлів зображення телефонів розширення .jpg, .jpeg, .png за допомогою npm-пакета **multer**

## Встановлення проєкту

Клонувати репозиторій та встановити залежності:

npm install

## Конфігурація бази даних

Створити PostgreSQL database (наприклад, за допомогою sequelize-cli) й налаштувати параметри підключення в .env за наданим шаблоном .env.example

## Міграції

Для створення таблиць виконати:

npx sequelize db:migrate

## Seeders

Для додавання тестових даних:

npx sequelize db:seed:all

## Запуск застосунку

Скрипти для запуску:

- **start** - звичайний запуск
- **dev** - запуск в dev-режимі через nodemon із застосуванням змінних оточення прописаних у файлі .env за допомогою npm-пакета dotenv
