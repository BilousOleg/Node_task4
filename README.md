# Node.js. Sequelize Model

Навчальний проект для практичного закріплення роботи з **Sequelize ORM**

## Модель Phone

Для моделі телефону реалізовано:

- додавання нового телефону,

- отримання списку телефонів (3-я сторінка при перегляді по 4 телефони на сторінці, упорядкованих за роком виробництва),

- отримання списку телефонів певного року видання,

- отримання списку телефонів старше 2020 року випуску,

- оновлення розміру оперативної пам'яті телефону з id: 1,

- оновлення (додавання) нфс всім телефонам 2021 року випуску,

- видалення телефону з id: 2.

- видалення телефонів 2010 року випуску.

## Для керування структурою бази даних використовуються Sequelize migrations.

## Для тестових даних використовуються Sequelize seeders.

## В моделях Sequelize визначені:

- типи даних;
- allowNull;
- defaultValue;
- model-level validators;
- унікальні обмеження;
- обмеження CHECK на рівні бази даних.

## Встановлення проєкту

Клонувати репозиторій та встановити залежності:

npm install

## Конфігурація бази даних

Створити PostgreSQL database (наприклад, за допомогою sequelize-cli) й налаштувати параметри підключення в:

config/config.json

## Міграції

Для створення таблиць виконати:

npx sequelize db:migrate

## Seeders

Для додавання тестових даних:

npx sequelize db:seed:all

## Запуск застосунку

Запустити на виконання файл index.js:

node .

Або з використанням скрипту **start** в package.json:

npm start
